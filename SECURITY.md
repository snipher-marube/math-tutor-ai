# Security policy

## Supported versions

This project is in early development. Only the latest code on `main` gets security fixes.

## Reporting a vulnerability

**Please don't open a public issue for security problems.**

Report privately through GitHub: go to the **Security** tab of this repository, then **Report a vulnerability** (GitHub private vulnerability reporting).

Please include:
- A description of the issue and its impact
- Steps to reproduce
- Any suggested fix

We aim to acknowledge reports within 7 days. Because our users are children, we also treat **child-safety issues** (for example, a way to make the tutor produce harmful content) as security issues. Report those the same way.
